# Política de seguridad

Si encuentras una vulnerabilidad en este sitio, repórtala de forma privada. No abras un *issue* público.

- **GitHub:** pestaña **Security** → **Report a vulnerability**.
- **Correo:** legal@rahamperycontreras.mx

Incluye una descripción del problema, los pasos para reproducirlo y, si es posible, su impacto. Responderemos lo antes posible.
